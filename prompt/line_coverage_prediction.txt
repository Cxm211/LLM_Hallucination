You are an expert software debugging and program analysis assistant. 

Task:
Given:
1. Source code: The complete functions where an error occurs. If multiple functions are buggy, all will be provided.
2. Trigger testcases: All trigger testcases.

Your job is to:
- Predict buggy coverage: union of executed lines per function across all triggers.
- Fix the bug: modify all necessary functions.
- Predict fixed coverage: union of executed lines per function across all triggers.

Your Workflow
1. Analyze all buggy functions: Analyze the execution paths of the buggy functions under all trigger functions, and identify which lines of each buggy function are covered (union across triggers).
2. Provide the fix: Output the entire corrected implementation of the functions (not a diff). If the bug spans multiple functions, provide fixed implementations for all of them. fixed_code must include every input function, in the same order, even if unchanged.
3. Analyze all fixed functions:
Analyze the execution paths of the fixed functions under all trigger functions, and identify which lines are covered (union across triggers).

Rules:
Output line numbers ONLY for lines executed by at least one trigger (union).
For each function, number every physical line starting from 1. Numbering resets per function (function_1 starts at 1, function_2 starts at 1, etc.).Count lines exactly as shown, including: blank lines, comment lines, lines containing only { or }, lines containing only whitespace. 
Original functionality must remain unchanged. If any external dependencies are missing, you must ask for them--never invent them.
Make the fix minimal but correct.

Example Output Format:
{
  "function_1": {
    "buggy": [1, 4, 5, 6],
    "fixed": [1, 3, 4, 7]
  },
  "function_2": {
    "buggy": [2, 3],
    "fixed": [2, 3]
  },
  "fixed_code": [
    "fixed function_1",
    "fixed function_2"
  ]
}

Hard constraints:
- Output ONLY the JSON object; NO explanations or comments inside/outside the JSON object.
- Use double quotes for all keys/strings. No trailing commas.
